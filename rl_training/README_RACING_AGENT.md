# PPO Racing Agent: Speed + Lateral Offset

This is the first clean combined longitudinal/lateral RL pipeline.

## Observation

```text
[current_speed, cross_track_error, heading_error, upcoming_curvature_abs]
```

## Action

```text
[normalized_speed, normalized_lateral_offset]
```

- `normalized_speed` is clamped to `[0, 1]`.
- `normalized_lateral_offset` is clamped to `[-1, 1]`.

The environment maps them to physical requests:

```text
target_speed = min_speed + normalized_speed * (max_speed - min_speed)
lateral_offset = normalized_lateral_offset * max_lateral_offset
```

Then it applies simple rate limits:

```text
max_speed_delta_per_step
max_lateral_delta_per_step
```

## Control Layer

The shifted path is generated by shifting the centerline along each waypoint's local normal:

```text
normal = [-sin(yaw), cos(yaw)]
shifted_point = centerline_point + lateral_offset * normal
```

Pure pursuit then follows this shifted path.

## Training example

```bash
python3 scripts/train_ppo_racing.py \
  --map_path /path/to/levine_hall_scanned \
  --map_ext .png \
  --centerline_csv /path/to/centerline_points_smooth.csv \
  --sx <start_x> --sy <start_y> --stheta <start_theta> \
  --total_timesteps 100000 \
  --model_dir models \
  --model_name ppo_racing_agent_100k \
  --min_speed 0.5 \
  --max_speed 4.0 \
  --max_lateral_offset 0.35
```
