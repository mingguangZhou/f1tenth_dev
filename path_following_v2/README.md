# path_following_v2 clean raceline-following baseline

This package is a minimal ROS 2 Foxy baseline for following the final smoothed raceline generated by `centerline_tools`.

It intentionally keeps only two runtime modules:

1. `path_generator_node`
   - subscribes to `/raceline_waypoints` as `std_msgs/Float64MultiArray`
   - expects rows of `[index, x, y, yaw, curvature, curvature_abs]`
   - extracts a local forward window from the global raceline
   - publishes `/path_following_v2/local_path` as `nav_msgs/Path`
   - publishes `/path_following_v2/speed_index` as `std_msgs/Float64`

2. `path_following_v2_node`
   - subscribes to `/path_following_v2/local_path`
   - subscribes to `/path_following_v2/speed_index`
   - converts the normalized speed index to physical speed using its configured speed range
   - computes steering with pure pursuit
   - publishes Ackermann commands to `/drive`

The package no longer contains the old RL-speed subscription or lateral-offset path generation logic. The interface is now clean for adding a future speed-RL agent: replace or override the speed-index producer, while keeping the follower unchanged.

## Topic interface

Required input from raceline publisher:

```bash
/raceline_waypoints
```

Internal topics:

```bash
/path_following_v2/local_path
/path_following_v2/speed_index
```

Control output:

```bash
/drive
```

Optional debug markers:

```bash
/path_following_v2/lookahead_marker
/path_following_v2/steering_marker
```

## Speed-index convention

The path generator publishes a normalized speed request:

```text
speed_index in [0, 1]
```

The follower maps it to physical speed:

```text
speed = speed_min + speed_index * (speed_max - speed_min)
```

The speed range is configured only in the follower:

```yaml
speed_min: 0.8
speed_max: 4.0
```

This keeps the generator/RL-side action independent from the final physical speed limits. Later, an RL agent can output a `speed_index` rather than directly outputting m/s.

## Baseline speed rule

For now, `path_generator_node` computes speed index from raceline curvature:

```text
speed_index = 1 / (1 + curvature_speed_gain * curvature_abs)
```

Then it clamps this value between:

```yaml
min_speed_index: 0.0
max_speed_index: 1.0
```

Relevant generator parameters:

```yaml
curvature_speed_gain: 2.0
curvature_lookahead_points: 10
```

## Speed-dependent pure pursuit

The follower supports speed-dependent lookahead:

```text
lookahead = clamp(min_lookahead + lookahead_speed_gain * speed,
                  min_lookahead,
                  max_lookahead)
```

Relevant follower parameters:

```yaml
use_speed_dependent_lookahead: true
min_lookahead: 0.6
max_lookahead: 1.6
lookahead_speed_gain: 0.25
```

## Build

From your workspace:

```bash
cd /sim_ws
source /opt/ros/foxy/setup.bash
colcon build --packages-select path_following_v2
source install/setup.bash
```

## Run

Start the raceline publisher first, for example:

```bash
ros2 launch centerline_tools raceline_publisher.launch.py
```

Then launch this package:

```bash
ros2 launch path_following_v2 path_following_v2.launch.py
```

## Quick checks

```bash
ros2 topic echo /raceline_waypoints --once
ros2 topic echo /path_following_v2/local_path --once
ros2 topic echo /path_following_v2/speed_index --once
ros2 topic echo /drive --once
```

Expected active nodes:

```bash
/path_generator
/path_following_v2
```
